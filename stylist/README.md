# Atelier — персональный ИИ-стилист с 3D-примерочной

Веб-приложение, которое знает весь ваш гардероб, ваши мерки и календарь. Каждый вечер оно готовит образ на завтра с учётом погоды, мероприятия, дороги и трендов.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Сегодня** | Погода на завтра, события, готовый образ на 3D-аватаре, прогноз на неделю, «давно не надевали» |
| **Стилист** | Подбор 3 образов: погода (Open-Meteo), дресс-код, повод, транспорт и маршрут (OSRM), сколько идти пешком (каблук + 3 км = предупреждение и «возьмите сменку»), причёска и макияж (для мужчин — груминг), чего не хватает |
| **Гардероб** | Все вещи по 19 категориям (брюки, платья, пиджаки, обувь, ремни, головные уборы, украшения…), поиск, фильтры, статусы (в стирке/ремонте/архив), статистика носки и цена за выход |
| **Добавление вещей** | 1) фото вещи → фон вырезается нейросетью в браузере, Claude заполняет карточку; 2) **фото себя в образе** → нейросеть SegFormer находит на фото верх, низ, платье, обувь, сумку, шапку, ремень, шарф и вырезает каждую вещь отдельно; 3) ссылка на товар WB/Ozon/Lamoda; 4) вручную |
| **Примерочная** | Параметрический 3D-аватар по 13 меркам (рост, обхваты, длина ног и рук, стопа…) + одежда слоями: заправленная рубашка, расстёгнутый жакет, пальто, юбки разной длины и клёша, каблуки, сапоги, шляпы, сумки, украшения |
| **Образы** | Сохранённые шаблоны со снимком 3D-аватара, рейтингом и тегами |
| **Календарь** | События с типом, дресс-кодом, местом и транспортом, импорт/экспорт `.ics`, «подготовить неделю», вечерние напоминания |
| **Зеркало** | Оценка образа по фото с камеры или из галереи, режим **Live** — оценка каждые 15 секунд, пока вы переодеваетесь |
| **Тренды и шопинг** | Актуальные тренды через веб-поиск Claude (с источниками), капсулы из вашего гардероба + список покупок, поиск вещей в российских магазинах под ваши размеры |
| **Чат** | Стилист, который знает гардероб, мерки, погоду и календарь; можно прикрепить фото |
| **Профиль** | Мерки, тип фигуры, размеры RU/INT, внешность, стиль, бюджет, комфорт (макс. каблук, сколько км на каблуке), экспорт/импорт данных |

Работает и **без ключа ИИ**: локальный движок подбирает образы по правилам (погода, формальность, сочетаемость цветов, каблуки vs расстояние, свежесть вещей), фон вырезается в браузере, капсулы собираются по шаблонам.

## Запуск

```bash
cd stylist
npm install
cp .env.example .env         # вставьте ANTHROPIC_API_KEY (необязательно)
npm run dev                  # веб: http://localhost:5173, API: http://localhost:8787
```

Продакшен:

```bash
npm run build
npm start                    # отдаёт и API, и собранный фронтенд на PORT (8787)
```

Проверки: `npm run typecheck`, `npm test`.

## Архитектура

```
stylist/
├── shared/        общие типы, каталог категорий, движок подбора, цвет, тип фигуры
├── server/        Express: Claude API, погода, геокодинг, маршруты, поиск в магазинах
├── src/
│   ├── components/avatar/   параметрическое тело + генерация 3D-одежды (three.js)
│   ├── lib/                 вырезание фона, сегментация одежды, планировщик, ics
│   └── pages/               10 разделов приложения
└── tests/         юнит-тесты движка
```

- **Данные** хранятся локально в браузере (IndexedDB через Dexie). Экспорт/импорт JSON — в профиле.
- **ИИ**: Claude (модель задаётся `STYLIST_MODEL`, по умолчанию `claude-opus-5`) — структурированный вывод для карточек вещей, образов, оценок и капсул; серверный веб-поиск — для трендов и магазинов; включён серверный fallback при отказе модели.
- **Нейросети в браузере**: `@imgly/background-removal` (удаление фона) и `Xenova/segformer_b2_clothes` через transformers.js (разбор фото в образе). Модели скачиваются при первом использовании; если они недоступны — упрощённое вырезание и распознавание через Claude.
- **Внешние API без ключей**: Open-Meteo (погода, 16 дней), Nominatim (адреса), OSRM routing.openstreetmap.de (маршруты).

> Лицензии: `@imgly/background-removal` распространяется под AGPL-3.0 — для личного использования это не проблема, для коммерческого продукта замените на модель с подходящей лицензией.
