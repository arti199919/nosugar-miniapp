# План разработки Atelier

## Этап 1 — MVP (сделано)

- [x] Каркас: Vite + React + TypeScript + Tailwind, сервер Express, общий код `shared/`
- [x] Модель данных: вещи, профиль с мерками, образы, события, планы, чат (IndexedDB)
- [x] **1. Гардероб по категориям** (19 категорий, подтипы, цвета, узор, материал, сезоны, формальность, тепло, стиль, статус, цена, статистика носки)
- [x] Добавление вещей: фото вещи → вырезание фона → ИИ-карточка; фото в образе → сегментация на отдельные вещи; ссылка на товар; вручную; демо-гардероб
- [x] **2. 3D-аватар по меркам** и примерка всей одежды слоями (верх/низ/платье/комбинезон/трикотаж/жакет/верхняя одежда/обувь с каблуком и голенищем/ремень/шарф/головные уборы/сумки/украшения/очки/часы/колготки)
- [x] **3. Условия дня**: погода по часам, мероприятие и дресс-код, транспорт, маршрут, сколько идти пешком, время на улице → правила (каблук на длинной дистанции, юбка-макси на велосипеде, сандалии в дождь…)
- [x] **4. Тренды**: веб-поиск Claude по модным изданиям с источниками, кэш на неделю; тренды учитываются при подборе
- [x] **5. Капсулы**: сборка из гардероба, сочетания, список покупок с приоритетом и бюджетом
- [x] **6. Шаблоны образов** со снимком аватара, тегами, рейтингом
- [x] **7. Причёска и макияж** (груминг для мужчин) под образ, погоду и событие
- [x] **8. Живая оценка фото**: камера, Live-режим, разбор по аспектам и быстрые правки
- [x] **9. Календарь**: события, импорт/экспорт .ics, подготовка на неделю, вечернее напоминание
- [x] **10. Поиск вещей в магазинах РФ** (WB, Ozon, Lamoda, Яндекс Маркет, Золотое Яблоко, сайты брендов) под размеры клиента
- [x] Чат со стилистом (стриминг, фото, контекст гардероба/погоды/календаря)
- [x] Офлайн-режим без ключа ИИ, тёмная/светлая тема, мобильная вёрстка, PWA-манифест, совместимость с Telegram Mini App
- [x] Юнит-тесты движка подбора

## Этап 1.5 — по ответам (сделано)

- [x] Гардероб по умолчанию — женский, использование в браузере с иконкой (PWA: манифест, иконки, service worker, iOS-метатеги)
- [x] Деплой: `render.yaml` (Render Blueprint) — HTTPS-ссылка для iPhone
- [x] **Аватар по фото**: 3D-лицо из селфи (MediaPipe Face Landmarker, текстура из фото, мягкий переход в тон кожи) + мерки по фото анфас/профиль (MediaPipe Pose + силуэт, обхваты по эллипсу, вычитание рук, проверка позы и правдоподобия)
- [x] **Цветотип по селфи**: локально по цветам кожи/волос/глаз + точный разбор Claude; палитра влияет на подбор вещей у лица
- [x] **Образ по фото-примеру**: Claude (или SegFormer локально) разбирает референс и подбирает похожие вещи из гардероба, недостающее — в поиск
- [x] **Apple Календарь**: подписка по ссылке iCloud, автосинхронизация, повторяющиеся события (RRULE), «Добавить в Apple Календарь»

## Этап 2 — ближайшее

- [ ] **Фотореалистичная копия тела**: реконструкция фигуры SMPL-X по фото (например, Meshcapade) и импорт GLB-аватара; одежда через VTON на ваше фото
- [ ] Фотореалистичная примерка: виртуальная примерка на ваше фото (VTON-модели вроде IDM-VTON / Kolors через fal.ai или Replicate) как второй режим рядом с 3D
- [ ] Причёска по селфи (форма и длина волос из сегментации), а не шаблонная
- [ ] Лицо в 3/4 и профиль: несколько селфи → полная текстура головы
- [ ] Текстура вещи на 3D из её фото (проекция вырезанной вещи на выкройку)
- [ ] Push-уведомления через Service Worker (сейчас напоминание работает, пока открыта вкладка) и бот в Telegram «что надеть завтра» в 20:00
- [ ] Синхронизация с Google/Яндекс/Apple Calendar по ссылке (CalDAV/ICS-подписка), а не только импорт файла
- [ ] Цены и наличие размеров напрямую из карточек WB/Ozon (партнёрские API), отслеживание скидок на вещи из списка покупок

## Этап 3 — идеи

- [ ] **Дневник носки** с аналитикой: цена за выход, «мёртвые» вещи, сезонные отчёты, что продать на Авито
- [ ] **Чемодан**: список вещей в поездку по прогнозу в городе назначения и плану событий
- [ ] **Стирка и уход**: вещи «в стирке» автоматически исключаются, напоминания о химчистке по составу
- [ ] **Цветотип по селфи**: определение подтона и палитры через Claude
- [ ] **Образ по фото-референсу**: «хочу как на этом фото» → собрать из своего гардероба + докупить недостающее
- [ ] **Совместимость пар**: образы для двоих на мероприятие
- [ ] **Голосовой режим** утром перед зеркалом
- [ ] **Сканер бирок**: состав и размер с фото бирки
- [ ] Импорт истории заказов с маркетплейсов (скриншоты «Мои покупки» → вещи в гардероб)

## Ответы на вопросы

- Гардероб: женский. Использование: браузер + иконка на экране (PWA). Календарь: Apple. Синхронизация: не нужна.
- Аватар: максимально реалистичный, копия пользователя — сделано лицо из селфи и мерки по фото; следующий шаг — фотореалистичная примерка (см. этап 2).
